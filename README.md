# Back End Developer Roadmap

This repository contains notes, resources, and a structured learning path based on the freeCodeCamp Back End Developer Roadmap video.

## Goal

Build a clear understanding of the technologies and concepts required to become a modern Back-End Developer.

## Learning Areas

### 1. Programming Fundamentals

* Variables
* Functions
* Data Structures
* Algorithms
* Object-Oriented Programming

### 2. Version Control

* Git
* GitHub
* Branching
* Pull Requests

### 3. Databases

* SQL
* PostgreSQL
* Database Design
* Indexing

### 4. APIs

* REST APIs
* JSON
* HTTP Methods
* Authentication

### 5. Backend Frameworks

* Node.js
* Express.js

### 6. Authentication & Security

* JWT
* Sessions
* Cookies
* Password Hashing
* OWASP Basics

### 7. Deployment

* Linux Basics
* Cloud Platforms
* CI/CD
* Docker
